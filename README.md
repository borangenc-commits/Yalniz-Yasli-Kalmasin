# Yalniz-Yasli-Kalmasin
JavaScript Uygulamaları dersi için hazırladığım Yalnız Yaşlı Kalmasın adlı projem
Mahallede yardıma ihtiyaç duyan bireylerle gönüllü insanları buluşturmayı amaçlayan JavaScript ön yüz projesi.

## Özellikler
- Yardım talebi oluşturma
- Talep kartlarını listeleme ve filtreleme
- Gönüllü olarak talep üstlenme
- Talep durumunu güncelleme

## Teknolojiler
HTML, JavaScript
